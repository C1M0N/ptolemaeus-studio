# 交接文档：学科纹章实验室

给接手的 AI：先读这一份，再读 [PRINCIPLES.md](PRINCIPLES.md)（底层原理）、[README.md](README.md)（怎么运行）、[CONTRACT.md](CONTRACT.md)（渲染器接口）。
代码在分支 `claude/intelligent-bell-jwhzn5`（目录 `logo-lab/`）。仓库里其他东西与本项目无关，不用管。

## 1. 用户要什么

- 给**每个学科、每门课程**（课程代码，如 CS 311、MATH 414）程序化生成一个纹章，像图腾、盾徽、家纹。覆盖所有学科，是一套完整的"视觉语言"。
- 要有强烈的个人风格，要美。用户觉得 MIT Media Lab 的程序化标志"有点丑"，要做得比它好。
- 生成依据是语义：最初的想法是一个 16×16 的矩阵，256 种属性，每格亮度 0–255。用户最关心的难点是"这 256 种属性怎么选"。
- 用户希望从底层想清楚：盾徽为什么这么设计、家纹怎么组合意义、文字和字形怎么承载意义（见 PRINCIPLES.md）。
- 每个思路放一个分支，做成可以看的 demo。用户用中文交流，喜欢直接看图。

## 2. 用户反馈的历史（按时间，越往后越重要）

1. 第一轮做了 9 个思路（纹章语法、盾徽、家纹、部首、卦象、符印、矩阵、形态、代码字形）。用户只留了**矩阵、形态、代码字形**，"其他都废掉"。
2. 用户的新想法：256 维矩阵只是生成图形的要素。**扩散的学科（属性分布宽）图形应该更散，统一的学科更像一个圆**；用整个矩阵生成形状，再用特征点去修饰。要求参考近年的实验性生成艺术。
3. 做了"生长"（B）和"墨团"（C）。用户喜欢**墨团**。
4. 用户要求每门课都有自己的图案（如 CS 311 系统工程、CS 464 计算理论），要找到能把 CS、AI、数学、统计区分开的内在特征，课号可以"在概念上叠加"出新形状。
5. 用户的三条要求（原话）：
   - "加灰度"
   - "不要做方向，用组成形状体素的不同形状来区分，你发散思考一下"（之前我用"往哪个方向偏"表示学科性质，用户否定了）
   - "不同的课应该是根据语义重新生成的，因为很多门课是交叉的。Math 414 和 Stat 414 本质就是同一门课，不能因为科目代码不一样，就把形状做成完全不一样的"
6. 体素版做出来后，用户说："全都是一个圆，而且不同科目之间根本分不清楚"，"全是圆形让我看着难受"。**用户非常反感圆形。**
7. 于是改成了现在的"墨迹"（见第 4 节）。用户还没有对这一版给出反馈。

## 3. 数据

- `data/attributes.json`：256 个属性 = 16 个领域 × 16 个（存在 元素 色彩 感官 形态 运动 生物 心智 正面情感 负面情感 价值 社会 人造 文化 自然 关系），每个领域 8 对反义词。
- `data/rubric.md`：打分规则，只用 60 / 120 / 190 / 255 四档，每个词 18–40 个非零属性。
- `data/ratings.json`：71 个日常词；`data/ratings_disciplines.json`：48 个学科。都由 Claude 打分，再由另一个 Claude 复核。
- `data/courses.json`：40 门示例课（CS、AI、MATH、STAT 各约 10 门），`data/ratings_courses_*.json` 是它们的打分。MATH 414 和 STAT 414 是同一门交叉课（概率论），由两个互不知情的打分者分别打分（`x1`、`x2`），余弦相似度 0.94。
- `tools/build_data.py` 生成 `shared/semantics.js`：向量、属性频率、MDS 语义平面（`layouts.xy`）、16×16 网格布局、合成轴。

## 4. 现在的主角：墨迹（`renderers/field.js`）

- 每个非零属性在语义平面（MDS，意思相近的属性挨着）上自己的位置滴一滴墨，大小 ∝ 亮度；权重 = 亮度^1.5 × idf（常见属性权重低）。
- 用最小生成树把墨滴连成一体，所以图形不会碎。
- 以加权重心居中，按均方根半径归一，**不旋转**（按各自长轴旋转会让几乎相同的向量转 90°，这个坑踩过）。然后沿竖轴对折，像罗夏墨迹，所以所有图形都立着、对称。
- 用方格拼砖填充：每格的花样 = 该处主导属性所属领域（16 种花样），灰度 = 该属性的打分档位。下面铺一层很淡的轮廓"底墨"。
- 课程只用自己的向量生成，不以学科为底，不加门类标记；年级只用底部的小圆点表示。
- 画法还有 字形 / 墨迹实心 / 等高线；可调 对折、格数、墨量、灰度、底墨、图例。

检测：`node tools/measure.mjs field` 把每门课的纹章栅格化，两两比较。当前结果：MATH 414 ~ STAT 414 是 780 对里最像的一对；排第二的是 CS 464 计算理论 ~ MATH 461 数论；视觉相似度与语义相似度的 Spearman 相关只有 0.25。

## 5. 重要发现

- **语义上，系与系之间是打通的。** 按语义找最近的课，40 门课里只有 8 门最像本系的课：机器学习最像统计学习，计算机图形学最像计算机视觉，计算理论最像数论。所以纯语义生成时，每门课都能分开，但同一个系的课不会自动长成一家。
- 这和用户的两条要求有冲突："交叉课程要一样"（只看语义）与"一眼看出是哪个系"（需要系别信息）。我建议的折中是：语义决定墨迹，再加一个**不改变形状的系别外框或底纹**（像纹章里同一家族不同分支的标记）。已经问过用户，还没有回答。
- 试过但没用的：用 NMF 从语料自动学"语义部首"作为体素字母表——语料以日常词为主，数学和统计被合成一类；把课程分解成 48 个学科的组合（非负最小二乘）——有些结果说得通（人机交互 = 设计 + 心理学 + 美术），但噪声大（数据库系统 = 数学 + 法学 + 药学）。
- 求和得到的形状天然趋向圆团（很多高斯叠加），这是之前"全是圆"的根本原因之一。要保持形状差异，需要非线性的、保留个体结构的构造。

## 6. 可以接着做的事

1. 等用户回答：是否加系别外框/底纹。
2. 提高视觉相似度对语义相似度的跟随程度（目前 0.25），同时保持 414 这对最像。
3. 拼砖花样的可读性：16 种花样要靠图例；可以考虑更有意义的字母表。
4. 更多课程：用 `L.coursePrompt` 现场打分，或者用打分规则批量打分（两个打分者 + 复核）。
5. 每次改完：`python3 tools/build_data.py`（改了数据时）→ `python3 tools/make_pages.py` → 用 `node tools/shoot.mjs` 截图检查（浅色、深色、手机）→ 用 `node tools/measure.mjs field` 检查 414 这对是否仍然最像。

## 7. 工具速查

```sh
cd logo-lab
python3 tools/build_data.py                     # 数据 -> shared/semantics.js
python3 tools/make_pages.py                     # index.html + demos/
node tools/shoot.mjs "tools/harness.html?r=field&size=110" out.png 1100 1100        # 48 个学科
node tools/shoot.mjs "tools/harness.html?r=field&words=数学&course=0,101,221,414&size=120" out.png 1000 400   # 一个系的课
node tools/shoot.mjs "index.html?w=统计学&c=414#field" out.png 1280 2200            # 页面详情
node tools/measure.mjs field                    # 视觉 vs 语义相似度
```
