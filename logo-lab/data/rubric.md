# 打分规则（离线数据和网页里"现场打分"共用）

给词语 W 在 256 个语义属性上打 0~255 的分，表示这个属性在 W 上有多强。

| 分值 | 含义 | 例子（猴子） |
|---|---|---|
| 255 | 定义性、本质的 | 动物 |
| 190 | 强烈、典型 | 毛发、聪慧、灵活好动 |
| 120 | 明确的联想或文化含义 | 狡黠、幽默、森林 |
| 60 | 弱但真实的联想 | 东方（孙悟空、生肖） |
| 0 | 无关（默认） | 金属、数字 |

规则：
1. 绝大多数属性是 0。每个词给 18~40 个非零分。
2. 同时考虑：字面属性（物理、感官、形状）、典型场景、文化含义（以中文语境为主，兼顾普遍含义）。
3. 抽象词按联想打分（例：自由 → 飞翔、天空、开放、叛逆）。
4. 反义的两个属性很少同时高分。
5. 只有真正定义这个词的属性才给 255，一个词通常只有 1~3 个 255。
